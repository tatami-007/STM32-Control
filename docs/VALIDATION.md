# 验证记录

日期：2026-10-13。主机模拟结果和实物结果分别记录。

## 已验证的软件

- 参考仓库readme与IMU驱动/姿态源码已完整读取，原始下载件保存在本地references。
- ARM GCC 13.3.1：Debug/Release均构建通过，无编译警告。
- Debug：Flash 58756B/64KB，RAM 5672B/20KB；Release：Flash 45376B，RAM 5656B。
- 8组主机测试通过：PWM正反转与换向等待；速度目标正负跟踪、16位编码器溢出、超过30秒持续运行；
  角度正负跟踪和外壳倾斜；IMU故障停止且不自动重启；编码器无反馈堵转；命令解析和急停；
  Mahony姿态/角加速度；静止校准对运动、噪声、漂移的拒绝。
- 软件初值仅通过简化电机模型，不代表实际负载已稳定。

## 本版实机状态

- 已尝试读取COM5：操作系统返回找不到COM5，当前只枚举COM3/COM4。
- 已尝试Release烧录：OpenOCD `open failed`，没有写入新固件，未验证新固件实机行为。
- 前一版曾通过ST-LINK烧录并驱动电机，但存在抖动、反馈漂移、停机；这些不能作为本版通过证据。
- 待设备接回后：烧录校验、确认IMU配置读回和静止校准、正反转、确认CPR、速度PID整定、角度PID整定、两个视频。
