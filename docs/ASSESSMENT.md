## 视频一：VOFA数据与曲线

1. 展示主控、驱动、电机/编码器和IMU接线。
2. 运行pwm正反转及调速，展示I4计数变化。
3. speed设几个目标，画I2/I3；讲明RPM所用CPR。
4. 静止及缓慢转动IMU，画姿态、角速度、角加速度。保留通道名称/单位。

## 视频二：指定角度闭环

1. 固定电机外壳，棒和IMU牢固连接，手动水平、静止后z。
2. angle:5、angle:-5、angle:0，拍清棒的变化与I0/I1曲线。
3. 沿输出轴方向缓慢倾斜外壳，展示棒回调到设定方向。
4. 若过冲/抖动/停机，先整定或排障再录最终视频，不隐藏失败状态。
